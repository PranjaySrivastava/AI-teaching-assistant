# Changelog

All notable changes to the AI Teaching Assistant project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-06

### Added

- Initial monorepo architecture setup for Frontend, Node Service, and Python Service.
- Production-ready GitHub Actions CI workflows for PR quality checks, linting, tests, and builds.
- Next.js + TypeScript + Tailwind CSS frontend boilerplate with interactive algorithm visualizer and avatar viewport.
- Node.js Express + WebSocket orchestration backend boilerplate with health checks and unit tests.
- Python FastAPI speech & ML service boilerplate with Pytest and Flake8 support.
- Shared data contracts and schema definitions.
- Comprehensive documentation and local developer onboarding guides.
